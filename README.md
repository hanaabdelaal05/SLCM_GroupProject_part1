# SLCM_GroupProject_part1
## Team Hanan Mohamed and Hana Abdelaal
Group project for CS 430, exploring de-identified case data from SLCM serving families with children ages
0-5.
## What's in this repo
- 'notebook.ipynb' — Jupyter notebook with our full analysis, cleaning steps, plots, column triage, and cleaning log
- 'Figure1.png' :Reconnect / Rethink / Rebuild diagram
- 'Figure2.png' : Urgency / Duration quadrant diagram
- 'CS 430 project part 1 Report.pdf' : written report answering the five questions and "What did you get to know?"
- cleaned_intakes_masked.csv
- household_members_long_v2.csv
  
## About the data
Two files were used for this analysis:
- 'cleaned_intakes_masked.csv' — one row per intake ticket (639 rows × 93 columns; 426 are primary intake records, the rest are follow-up sub-tickets)
- 'household_members_long_v2.csv' — one row per additional household member (993 rows × 8 columns)
